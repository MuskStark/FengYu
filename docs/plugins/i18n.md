# Internationalization

## i18n 资源文件位置

`src/main/resources/i18n/`

文件名格式：`messages.properties`（默认/英文）、`messages_zh.properties`（中文）

基础名 `i18n.messages` — 即文件在 `i18n/` 目录下，文件名为 `messages.properties`。

## Key 命名约定

所有 key 必须以 `plugin.<slug>.` 为前缀，避免与宿主或其他插件冲突。

### 英文（默认）

路径：`src/main/resources/i18n/messages.properties`

```properties
plugin.star.exampleLabel=Example Label
plugin.star.exampleButton=Example Button
plugin.star.idle=Idle
plugin.star.running=Running...
plugin.star.error=Error
```

### 中文

路径：`src/main/resources/i18n/messages_zh.properties`

```properties
plugin.star.exampleLabel=示例标签
plugin.star.exampleButton=示例按钮
plugin.star.idle=空闲
plugin.star.running=运行中...
plugin.star.error=错误
```

## 注册 Bundle

在插件入口类的 `createView()` 中注册：

```java
@Override
public Node createView() {
    I18n.registerPluginBundle("i18n.messages", getClass().getClassLoader());
    return new {{Name}}PluginUi().getView();
}
```

**必须使用插件自己的 ClassLoader**（`getClass().getClassLoader()`），不能用系统 ClassLoader。

## 使用方式

| 方式 | 代码 | 说明 |
|------|------|------|
| 绑定到属性 | `I18n.bind(label.textProperty(), "plugin.xxx.key")` | 自动响应语言切换 |
| 获取值 | `I18n.get("plugin.xxx.key")` | 一次性获取，不自动更新 |
| 监听变化 | `I18n.addListener(runnable)` | 自定义刷新逻辑 |

## 重要规则

1. **两个文件必须使用完全相同的 key** — 缺失的 key 会回退到默认语言
2. **Key 前缀 `plugin.<slug>.`** 是约定而非强制，但能防止冲突
3. **注册必须在 UI 创建之前** — 否则 `I18n.get()` 和 `I18n.bind()` 返回原始 key 而非翻译文本
