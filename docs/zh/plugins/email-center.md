# 官方插件：邮件中心

邮件中心（`fan.summer.email`）是官方沙箱 `.fyp`。双语 Vue/Vuetify iframe 会跟随宿主语言和明暗主题，任务导航提供六个独立工作区：

| 工作区 | 能力 |
| --- | --- |
| 写邮件 | 直接输入收件人/抄送地址，或选择联系人标签，为每位主收件人生成一封独立邮件。 |
| 批量发送 | 解析附件文件名标签，计算收件人/抄送群组交集，预览并按附件标签各生成一封邮件。 |
| 联系人 | 联系人和标签增删改查、搜索筛选、批量分配标签及独立标签管理。 |
| 邮件归档 | 手动将 IMAP 邮件收取到授权目录，并分页查看归档元数据。 |
| 发送记录 | 搜索结构化确认任务和每封邮件的发送结果。 |
| 账户设置 | 管理多套 SMTP/IMAP 配置；密码只写，SMTP 测试与保存相互独立。 |

## 富文本与 Word 粘贴

写邮件和批量发送编辑器会保留邮件安全的 Word 格式子集：标题、字号和颜色、粗体/斜体/下划线、对齐、列表、链接及表格。Word 私有标记、脚本、不安全 URL/CSS 与 Word 内嵌图片会被移除。iframe 与 Worker 都会清洗 HTML；必要时 Worker 会自动生成纯文本正文。

## 文件名标签批量规则

附件标签取最后一个下划线到最后一个扩展名之间的文本：`report_East.pdf` 解析为 `East`。

对每个附件标签 `T`：

- 收件人(`T`) = 含标签 `T` 的联系人 ∩ 已选发送群组标签。
- 抄送(`T`) = 含标签 `T` 的联系人 ∩ 已选抄送群组标签。
- 同一地址同时命中时，收件人优先，并从抄送中移除。
- 标签为 `T` 的全部文件只加入该标签对应的邮件。
- 公共附件会追加到每一封生成的邮件。
- 无主收件人的标签显示为跳过，无法解析标签的文件显示为忽略。

所有发送都必须先确认。准备阶段保存不可变快照且不会发送；只有 `confirm_send` 才执行 SMTP。本版本不提供失败项重试工作流。邮件收取也仅支持手动执行，不会后台轮询。

插件权限恰好是 `database`、`network.email`、`files.read` 和 `files.write`。SMTP/IMAP 密码经 AES-GCM 加密，账户 RPC 永不返回密码。
