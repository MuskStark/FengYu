# 功能介绍

SwissKitJ 提供 8 个内置工具，按分类组织，并支持外部插件。

## 分类

| 分类 | 用途 |
|------|------|
| 全部 | 显示所有工具 |
| 文本 | 文本处理 |
| 图片 | 图片工具 |
| 开发者 | 开发者工具 |
| 网络 | 网络/通信 |
| 其他 | 杂项 |

## 内置工具

### AI 聊天（开发者）

与本地 GGUF 格式的 LLM 模型对话。支持：

- 加载多种量化格式的 GGUF 模型（Q3_K、Q5_0、Q4_0、Q8_0、IQ4_NL）
- 实时生成令牌流的流式推理
- 支持工具调用和自定义工具定义
- 带历史记录的聊天会话管理
- JNI 原生加速层进行推理

### JSON 格式化（开发者）

格式化、压缩和验证 JSON 数据。粘贴原始 JSON 获取格式化输出。

### Base64（开发者）

将文本编码为 Base64，或将 Base64 字符串解码回明文。

### 哈希计算器（开发者）

计算文本输入的 MD5、SHA-1、SHA-256 和 SHA-512 校验和。

### Markdown 编辑器（文本）

实时 Markdown 编辑器，带左右对照预览。

### 颜色转换器（图片）

在 HEX、RGB 和 HSL 颜色格式之间转换，带实时颜色预览色块。

### 邮件（网络）

通过 SMTP 配置发送邮件：

- 按收件人标签单发和群发邮件
- 带格式工具栏的富文本编辑器
- 按标签文件夹路由附件
- 带标签管理的通讯录
- 已发送邮件历史记录

### Excel 拆分器（其他）

使用多步骤向导拆分 Excel 文件：

1. **选择文件** — 选择源 `.xlsx` 或 `.xls` 文件
2. **分析** — 自动检测所有工作表及其表头
3. **拆分模式** — 按工作表拆分、按列拆分或复杂拆分（多配置）
4. **输出** — 选择输出目录并开始处理

## 系统功能

### 插件商店

从在线目录浏览安装插件，或加载本地插件 JAR。已安装的插件会自动热重载。

### 设置

配置 SMTP 邮件服务器设置，管理邮件通讯录和标签，查看已安装插件。

## 插件系统

SwissKitJ 通过两种方式发现插件：

- **内置工具** — 在启动时由 `BuiltinToolRegistrar` 直接注册
- **外部插件** — 实现 `SwissKitJPlugin`，在 `META-INF/services/` 中声明，将 JAR 放入 `plugins/` 目录，支持热重载

详见[架构说明](architecture.md)了解插件如何加载，以及[开发指南](development.md)了解如何构建自己的插件。
