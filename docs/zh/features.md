# 功能介绍

FengYu 提供 9 个内置工具，按分类组织，并支持外部插件。

## 分类

| 分类 | 用途 |
|------|------|
| 全部 | 显示所有工具 |
| 文本 | 文本处理 |
| 图片 | 图片工具 |
| 开发者 | 开发者工具 |
| 网络 | 网络/通信 |
| 其他 | 杂项 |

## 内置工具

### AI 聊天（开发者）

支持多种后端的 AI 对话。功能包括：

- **本地 GGUF 模型** — 加载并运行本地模型，JNI 原生加速
- **OpenAI 兼容 API** — 连接任何 OpenAI Chat Completions 端点
- **Anthropic Claude API** — 连接任何 Anthropic Messages API 端点
- 实时生成令牌流的流式推理
- 支持工具调用和自定义工具定义
- 带历史记录的聊天会话管理
- 启动时自动激活已配置的后端
- 设置中的 **Java/Native 推理引擎切换** — 原生后端在首次打开 AI 工具时延迟加载
- **斜杠命令** — 输入 `/` 列出工具、查看帮助，或直接调用工具而无需模型推理；支持直接执行和引导式模型参数提取

### JSON 格式化（开发者）

格式化、压缩和验证 JSON 数据。粘贴原始 JSON 获取格式化输出。

### Base64（开发者）

将文本编码为 Base64，或将 Base64 字符串解码回明文。

### 哈希计算器（开发者）

计算文本输入的 MD5、SHA-1、SHA-256 和 SHA-512 校验和。

### Markdown 编辑器（文本）

实时 Markdown 编辑器，带左右对照预览。

### 颜色转换器（图片）

在 HEX、RGB 和 HSL 颜色格式之间转换，带实时颜色预览色块。

### 邮件（网络）

通过 SMTP 配置发送邮件：

- 按收件人标签单发和群发邮件
- 带格式工具栏的富文本编辑器
- 按标签文件夹路由附件
- 带标签管理的通讯录
- 已发送邮件历史记录

### 浏览器自动化（开发者）

通过自然语言指令自动化 Web 浏览器：

- 使用系统已安装的 Chrome、Edge 或 Chromium —— 无需额外下载浏览器
- 观察-思考-行动循环，包含页面 DOM 快照和 CSS 选择器定位
- AI 规划器决定操作（导航、点击、输入、提取、滚动等）
- 注册为 `browser_automate` AI 工具 —— 可从 AI 聊天调用

### Excel 拆分器（其他）

使用多步骤向导拆分 Excel 文件：

1. **选择文件** — 选择源 `.xlsx` 或 `.xls` 文件
2. **分析** — 自动检测所有工作表及其表头
3. **拆分模式** — 按工作表拆分、按列拆分或复杂拆分（多配置）
4. **输出** — 选择输出目录并开始处理

## 系统功能

### 窗口自由调整大小

无装饰的玻璃态窗口通过 `WindowResizeHelper` 支持边缘和角落拖拽缩放。缩放检测使用屏幕坐标，确保跨平台兼容性，包括 macOS 上 `stage.isMaximized()` 不可靠的 `StageStyle.TRANSPARENT` 场景。

### 插件商店

通过可搜索、可筛选的卡片网格从在线目录浏览安装插件。显示安装状态指示和与本地已安装插件的版本比较。也支持加载本地插件 JAR。已安装的插件会自动热重载。

### 工具收藏

通过点击工具卡片或详情面板上的星标图标收藏任意工具。收藏数据持久化到数据库，重启后保留。侧边栏"收藏"分类可筛选仅显示已收藏的工具。

### 插件管理

从详情面板直接卸载外部插件，带确认对话框。安装通知（Toast）确认从在线商店或本地 JAR 安装插件成功。

### 设置

配置 SMTP 邮件服务器设置，管理邮件通讯录和标签，查看已安装插件。

## 插件系统

FengYu 通过两种方式发现插件：

- **内置工具** — 在启动时由 `BuiltinToolRegistrar` 直接注册
- **外部插件** — 实现 `SwissKitJPlugin`，在 `META-INF/services/` 中声明，将 JAR 放入 `plugins/` 目录，支持热重载

详见[架构说明](architecture.md)了解插件如何加载，以及[开发指南](development.md)了解如何构建自己的插件。
