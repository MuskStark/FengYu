# 文档

**蜂语 FengYu**（Infinia）是一个模块化的 Web + 桌面工具箱：仅绑定环回地址的无头
Spring Boot 后端、可在浏览器或 Electron 桌面窗口中运行的 Vue 3 + Vuetify 3 界面，
以及两个对等的扩展面 —— `.fyp` 插件与 `.fys` 技能 —— 由「规划-执行」智能体统一调度。
