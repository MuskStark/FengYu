# v3.2.0 一致性修复批次 — 实施计划(讲义)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 v3.2.0 发布前消除主题 token 违规、交互虚假承诺、API 命名遗留(glass)与插件文档错误,让主程序 UI 与插件 SDK 表面保持一致。

**Tech Stack:** Java 21 / JavaFX / Maven(仅 IDEA 内置)/ JUnit 5 / docsify 文档。

### Task 4: 实现 ⌘K/Ctrl+K 搜索快捷键与 Esc 语义

搜索栏显示 `⌘K` 提示(`ContentArea.java:256`)但全应用没有任何快捷键实现——虚假承诺。同时补齐 Esc:优先关闭详情面板,其次清空搜索。Windows/Linux 上提示文字应为 `Ctrl+K`。

- [ ] **Step 1: ContentArea 增加两个公共方法**

在 `ContentArea.java` 的 `showToolGrid()` 方法之后插入:
```java
    /**
     * Focuses the search field if it is currently visible (tool-grid mode).
     * Invoked by the global Cmd/Ctrl+K accelerator.
     */
    public void focusSearch() {
        if (searchField.getParent() != null && searchField.getParent().isVisible()) {
            searchField.requestFocus();
            searchField.selectAll();
        }
    }

    /**
     * Handles a global Escape press: closes the detail panel first,
     * then clears an active search query.
     *
     * @return {@code true} if the event was consumed
     */
    public boolean handleEscape() {
        if (detailPanel.isPanelOpen()) {
            detailPanel.hide();
            return true;
        }
        if (!currentQuery.isEmpty()) {
            searchField.clear();
            return true;
        }
        return false;
    }
```

```java
    /**
     * Registers scene-level keyboard shortcuts once the scene is attached:
     * Cmd/Ctrl+K focuses the search bar, Escape closes the detail panel
     * or clears the search query.
     */
    private void wireShortcuts() {
        sceneProperty().addListener((obs, oldScene, scene) -> {
            if (scene == null) return;
            scene.getAccelerators().put(
                new KeyCodeCombination(KeyCode.K, KeyCombination.SHORTCUT_DOWN),
                contentArea::focusSearch);
            scene.addEventFilter(KeyEvent.KEY_PRESSED, e -> {
                if (e.getCode() == KeyCode.ESCAPE && contentArea.handleEscape()) {
                    e.consume();
                }
            });
        });
    }
```
(主 Scene 只 set 一次,监听器不会重复注册;`SHORTCUT_DOWN` 在 macOS 映射 ⌘、Windows/Linux 映射 Ctrl。)

This guide covers everything a plugin author needs to change (or can newly use)
