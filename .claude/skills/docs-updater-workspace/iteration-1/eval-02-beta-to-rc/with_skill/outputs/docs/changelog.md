# Changelog

**v3.0.0-rc.1** — 2026-05-29

### ✨ New Features

- **Plugin Lifecycle**: Added `onActivate()` and `onDeactivate()` default methods to the `SwissKitJPlugin` interface, allowing plugins to hook into lifecycle events.

### ♻️ Changes

- **ToolCategory Enum**: Converted category strings to a `ToolCategory` enum (`DEV`, `TEXT`, `IMAGE`, `NET`, `OTHER`) for type-safe category handling.
