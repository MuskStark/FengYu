# Architecture

SwissKitJ v3.0.0-rc.1 is built on JavaFX 21. Plugins can now implement
`onActivate()` / `onDeactivate()` lifecycle callbacks. Categories use the
`ToolCategory` enum (DEV, TEXT, IMAGE, NET, OTHER).

See [3.0.0-rc.1 release](https://github.com/MuskStark/SwissKitJ/releases/tag/v3.0.0-rc.1).
