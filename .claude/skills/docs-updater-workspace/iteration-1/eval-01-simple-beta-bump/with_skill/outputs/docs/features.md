# Features

## Built-in Tools

### AI Chat (`DEV`)
AI-powered chat with support for OpenAI and Anthropic API backends.
- Markdown rendering in responses via WebView with dark theme
- Built-in AI tools: Base64, Hash, JSON Format, Color Convert
- Excel integration: analyze, configure, execute, query, and cancel tools for AI-powered split operations
- FunctionGemma native tool calling protocol support
- ToolExecutor and ToolSchemaBuilder for easy tool registration

### Email Archive (`NET`)
Built-in email archive tool with IMAP support.

### JSON Formatter (`DEV`)
Format, compress, and validate JSON data.

### Base64 (`DEV`)
Encode text to Base64 or decode Base64 strings.

### Hash Calculator (`DEV`)
Calculate hash digests (MD5, SHA-1, SHA-256) for text input.

## Plugin System

- **Background Execution**: Plugins can run tasks in the background with view caching and ToolCard indicator for running state.
