[h2] AI Agent
[p] A plan-and-execute agent decomposes goals into steps across Ollama, OpenAI, Anthropic, and DeepSeek — with approvals for sensitive actions.
[h2] Plugins (.fyp)
[p] Isolated .fyp packages — a JSON-RPC worker plus a micro-frontend UI — installable from the marketplace as capabilities the Agent can call.
[h2] Skills (.fys)
[p] Codex-style progressive-disclosure skills (.fys) that give the Agent on-demand domain knowledge and procedures for each business scenario.
[div] 🖥️
[h2] Cross-Platform
[p] The same Vue UI runs in a browser or an Electron desktop window on Windows, macOS, and Linux. The headless backend binds loopback only — your data stays on your machine.
[h2] Multi-Database
[p] First-launch wizard picks H2, SQLite, MySQL, or PostgreSQL. Passwords AES-GCM encrypted, machine-bound.
[h2] Built for Everyone
[p] English-first docs, a localized Vue UI (vue-i18n), and a Material Design 3 theme (Vuetify 3) with dark and light modes — shared with plugin micro-frontends.
[h2] From goal to workflow
[strong] Infinia
[p] (蜂语 / FengYu) is an
[em] AI-native orchestration platform

[p] plugins,
[code] .fys
[p] skills, and in-process AI tools — to carry it out. It runs as a headless Spring Boot backend, a Vue 3 + Vuetify 3 UI, and an optional Electron desktop shell.
