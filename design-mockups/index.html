Markdown 处理

fan.summer/markdown · v1.4.2 · stable

下载量 12,438类型 插件分类 文档处理更新 3 天前大小 2.1 MB

把文档工作交给智能体

Markdown 处理为 FengYu 智能体提供完整的 Markdown 能力：渲染预览、批量转换（PDF / HTML / Word）、表格整理与代码高亮。所有处理在本地完成，文档不出机器。

能力一览

  • 读取与写入 .md，保留原文格式与元数据
  • 批量导出 PDF / HTML / DOCX，支持自定义模板
  • 表格与列表智能重排，修复破损结构

快速使用

安装后，在对话里直接说「把 docs/ 下的说明文档导出成 PDF」即可。技能会自动注册为 markdown 工具组，供流程与定时任务调用。
